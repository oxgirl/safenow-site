Privacy policy

Last updated 18 November 2026. This policy covers the SafeNow iOS and Android apps and this website.

No account, no analytics, no SafeNow server

SafeNow has no account and no login. It does not include an analytics, advertising, crash, or tracking SDK. It does not sell personal information. There is no SafeNow server that receives your places, family notes, medical card, checklist ticks, language, or settings.

What stays on the device

Places, routes you save, the household plan and family medical card, checklist ticks, language, and settings are stored on the device (IndexedDB and local storage). Uninstalling the app or clearing the site data removes them. You can export a JSON or CSV file yourself if you want a copy.

Location, compass, and torch

SafeNow uses your location only on this device, to point the shelter compass and to show coordinates on the SOS screen. A last-known fix can be stored on the device so the compass can keep working if the GPS signal drops. Location used for those on-device features is not sent to SafeNow, because there is no SafeNow server for it.

The compass uses motion sensors so the arrow can turn with the phone. Those readings stay on the device. If you use the SOS torch, the app may ask for camera access only to turn on this phone’s flashlight. Camera frames are not uploaded and are not stored.

If you deny location, you can still type a latitude and longitude or search for a city name.

Network requests you can start while online

The app can work from data already on the phone. It does not need a network for the bundled guides, translations, or places you have already saved. If you choose to search for a city, update nearby shelter data, or save a walking-route or street-map area while you have a connection, the app sends that request to public OpenStreetMap services, not to a SafeNow server:

  • A place-name search or reverse-geocode request to Nominatim (nominatim.openstreetmap.org). That request includes the search text you typed, or coordinates if you asked the app to name a point.
  • A bounded map query to the public Overpass API (overpass-api.de) so OpenStreetMap places or walking streets in that area can be saved on the phone. That request includes a geographic bounding box.
  • Map tiles from OpenStreetMap (tile.openstreetmap.org) only if you ask to save or view a street map. Tile requests indicate the map area you viewed.

Those services can see the request and the network address it came from, under their own policies. SafeNow does not receive a copy. Official shelter lists that ship inside the app are read from files bundled with the app, not from a SafeNow backend. Map data is © OpenStreetMap contributors, ODbL.

Some guide screens include ordinary links to public references such as Ready.gov, the American Red Cross, CDC, or WHO. Those pages load only if you open the link.

This website

These pages are static files hosted on GitHub Pages. This site does not set a tracking cookie, does not include an analytics script, and does not use an account. GitHub, as the host, may process standard web-server logs such as IP addresses under GitHub’s own privacy policy.

Payments

This version does not take payment and does not include a store billing account or in-app purchase.

Contact

Questions about this policy can be sent through the SafeNow site issues page. See also support.
